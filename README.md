# wiser-analyser

A collection of interactive decision-support tools for people doing high-stakes work under uncertainty — particularly in AI safety, existential risk reduction, and other pressing cause areas. Also includes a navigator interface that allows you to easily find the right tool but does not yet link to each tool - you'll have to manually go to the suggested tool file, which lists a bunch of not yet built/finished tools as well as the ones available here. There will be many more tools soon - this is currently in partial + beta release.

## What These Tools Are

These are standalone HTML interfaces (except for the Multi-Criteria Decision Analysis tool, which is its own file set) for structured thinking methods drawn from intelligence analysis, decision science, operational research, systems thinking, and applied rationality. They're designed for:

- **Epistemic rigour without academic overhead** — serious methods made accessible
- **Solo or team use** — most tools work for individual analysis or facilitated workshops
- **Offline capability** — download any file and use it without internet
- **Transparency** — every calculation explained, every assumption surfaceable

The toolkit includes tools for uncertainty quantification (Monte Carlo, Fermi Estimation, Reference Class Forecasting), structured analysis (Pre-mortem, Red Team, Key Assumptions Check), multi-criteria decision-making (MCDA, Swing Weighting, AHP aggregation), systems mapping (Connection Circles, Design Structure Matrix), and more.

## Using the Tools

Each `.html` file is a complete, self-contained tool, except for the MCDA interface. You can:

- **Use online**: Visit the hosted version 
- **Use offline**: Download any file and open it in your browser
- **Save your work**: Most tools support JSON export/import for saving and resuming analyses

Start with the [Tool Navigator](comprehensive-tool-navigator.html) for an overview of which tool to use when.

## Philosophy

These tools embody a few commitments:

- **Reveal, don't obscure**: Complex methods should produce clarity, not mystification
- **Assumptions are hypotheses**: Surface them, test them, update them
- **Calibrated confidence**: Know what you know, and know what you're guessing
- **Practical rigour**: Sound enough to trust, accessible enough to actually use
- **Empower the user**: thanks to guidance, worked examples and resources, you'll learn to carry out more refined analyses without support

Influences include the rationalist tradition (LessWrong, CFAR), intelligence analysis tradecraft, decision science, systems thinking, and more.
